# Devlog #12 - Chopping trees DOWN

## 一句话
物理引擎 v1 完成：SVO 同质八分体当图节点做连通分量标注（DFS），实时刻断连体素；四元数叉乘不交换性让他调了三周「幽灵自转」。

## 内容要点
- **问题拆解**：体素物理 = ①识别断连（connected component labeling）+ ②碰撞检测响应。
- **CCL 用 DFS**：体素=图节点，面相邻=边（**6 连通，不含对角**——更简单也更符合直觉）；从断口处遍历即得新连通分量。
- **SVO 加速 CCL**（本集核心）：通用 CCL 算法是像素数线性时间（扫描线版缓存友好但仍是线性）；他把**同质八分体整体当一个图节点**——8³ chunk 本要处理 512 体素+全部邻边，现在 1 个节点搞定；过程把访问过的八分体写进**稠密位图**，O(1) 查询「某八分体是否属于该分量」，随后按位图从源体积摘除体素。实时可跑。
- **旋转响应**：四元数积分 + 接触点力矩求和近似（SAT 不直接给接触点，粗估即可）；手机在桌角的重心/接触直觉说明精确解需要无穷信息，近似是正路。
- **三周调试「幽灵自转」**（诊断方法论样板）：现象=物体自发获得无穷角速度。方法：①关掉除一根轴外的全部旋转（降成 2D）→②在物理各阶段间插打印、逐段核对输入输出→③发现两个物体打印的角速度相同但转向相反→锁定「角速度→角位置」转换代码→**四元数乘法不交换，他把乘号两边写反了**，一行修复。
- **自评局限**：逐对象独立处理（非约束式）→ 不能做多米诺牌堆倒下；未来应学 Teardown 的 constraint-based 物理。副业：多人后端 Go→Rust 重写。

## 对 gate 的启示
- **gate 的电路组件 flood-fill 与他的 CCL 是同一问题**：「同质八分体=单节点 + 稠密位图 O(1) 成员查询」可直接移植到 gate 的 cell 级 flood-fill——gate 已有 4KB bitmap/CellDirs 寻址链，把这个技巧用上后大块同材质区域（导线长直段、整片空气）的 flood 代价从 O(体素) 降到 O(节点)。
- 「编辑后从断口处局部 DFS」而非全图重扫，与 gate 的脏组件队列增量更新同构，他的位图摘除流程可参考。
- 四元数教训泛化：**任何不可交换/非对易的数学结构（四元数、矩阵、变换序）在代码里显式标注乘法顺序**。
- 三周调试法（单轴化→分段打印→找不变量矛盾）与 gate 的调试偏好完全一致，可作为疑难 bug 的标准流程。
