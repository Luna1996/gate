# Devlog #19 - Emissive voxels and fancy lighting

- 视频: https://youtu.be/VPetAcm1heI （13:08，2024）
- 类别: 光影 | ⭐⭐⭐ gate StateTable 发光 + 未来 GI 的总蓝图

## 一句话
路径追踪进入引擎：自创 radiance 函数让「发光体素」白送；为保逐体素纯色观感发明 GPU 逐体素光照 hashmap（原子 CAS + 时间复用）+ à-trous 边缘感知去噪。

## 内容要点
- **路径追踪目标**：AO（缝隙阴影）+ 发光体素的直接照明（体素→体素）。渲染方程 + Monte Carlo 半球采样（每像素 1 样本，实时）。
- **radiance 函数是自创的（艺术优先，非物理）**，三分支：
  1. 射线到天 → 预设天空色；
  2. 射线撞物体 → 环境色 × 按距离指数衰减（= AO）；
  3. 撞到**发光体素** → 直接返回其颜色。**三四行代码 = 面光源免费**，暗屋子里点灯全靠它；传统光栅化里这是额外开销，ray marching 里零成本。
- **噪声治理三级**：多样本（贵，排除）→ 重要性采样 → **去噪**。
- **GPU 逐体素 hashmap**（本集最核心发明，为保「每体素一色」观感）：
  - 帧首把可见体素塞进 hashmap；路径追踪像素把自己的光照值**原子 CAS 累加**到所属体素的均值槽；
  - 合成 pass：主 pass 的 unlit 色 × 逐体素平均光照 = 成品；
  - 附赠1：**时间降噪**——新帧 key 槽先用上一帧结果初始化再清旧帧（多帧平均，稳定）；
  - 附赠2：**直光降本**——原本每像素朝太阳投阴影射线，同体素多像素重复劳动；改为**每体素一条**独立 shader 投射，1660 Ti 上即使关路径追踪也省 1-2ms。
- **À-trous 小波滤波**：间接光先做大 blur 但**不跨物体边界**（边缘保持锐利），4 次迭代——收尾的最后一块拼图。
- **完整管线顺序**：beam 低分辨率预pass → 主 pass（unlit 色 + 注册可见体素进 hashmap）→ hashmap 用上帧初始化 → 直光 pass（每体素 1 条太阳射线）→ 间接光 pass（半分辨率随机射线）→ 4× à-trous → 累加进 hashmap → 合成 → 可选上采样+AA 后处理。GitHub 有 demo。

## 对 gate 的启示
- **发光体素 = gate 的 StateTable emissive 终极形态**：现在 StateTable 调制的是「自发光颜色直出」；按他的做法，下一步是 DDA/阴影射线撞到发光元件体素时把 StateTable 颜色作为 radiance 贡献回来——电路通电照亮周围体素就是这个公式，改动量极小（他的原话：一个 if）。
- **逐体素直光**（每体素一条阴影射线 + hashmap 复用）与 gate「逐体素平均光照」设想完全一致，且他给了量化收益（1660 Ti 省 1-2ms）——3.5d 软阴影调优时「每体素采样数」应作为独立旋钮。
- 时间复用 hashmap 思路 = gate 未来 GI（P9 DDGI）的前置技术； à-trous 边缘感知去噪同样是 P9/3.5d 的现成拼图。
- 他的管线顺序（beam 预热 → 主 → 直 → 间 → 滤波 → 合成）可直接作为 gate 光影管线的目标拓扑图。
