# Devlog #26 - My voxel physics engine was BROKEN - here's every fix

- 视频: https://youtu.be/R9bror0oqR0 （15:37，2025）
- 类别: 物理 | 物理 v3 全面翻修（每条 fix 都有诊断过程）

## 一句话
碰撞法线旋转不变性修复（球→圆角体素）、求解器从 split impulses 换 TGS + warm starting（堆叠 6 层不塌）、逐体素材质物理属性、破碎系统起步。

## 内容要点
- **新能力**：杠杆/扭矩正确（平衡梁撤一端正确倾倒）；0.5m 盒子可叠 6 层（第 7 层微晃）；杂乱堆叠不爆炸不嵌墙（v2 的 GitHub issue 关闭）；**逐体素材质属性**（密度/摩擦/弹性——钢比羽毛重，为将来流体沉浮铺垫）；**破碎/断裂**（硬碰撞分裂物体，对标 Teardown，半成品）。
- **碰撞检测修复**：
  - 体素分类 corner/edge/face/interior；只测 edge-edge 与 corner vs (corner/face/edge)；
  - v2 的 bug：把体素 bbox 平移到对方坐标系比 AABB——**对旋转不变**，法线算错 → 抖动；
  - Teardown 的球体近似旋转不变但**球不填满体积** → 可见下陷 + 多余摩擦（他用 2D 玩具引擎可视化论证）；
  - **他的折中方案：角/棱取球面、面保持全平面**——球-球测试外加少量平面-球测试 + 棱对棱的圆柱特例，数学量与球法相当，伪影消除。
- **求解器修复**：
  - split impulses（先积分再压速度再分开位置）因浮点精度让静止盒子上下振荡（jitter）；
  - 关键洞察：**先解速度约束再积分位置**（速度已归零则位置不动）；
  - 试了 PGS/NGS，最终选 **TGS（temporal Gauss-Seidel）**：加力→解速度约束→更新位置的内循环多次迭代，**复用已有接触、不重跑碰撞检测** → 收敛快；
  - **Warm starting**：以上一帧接触力为初值；体素场景的天然优势——**用「两个碰撞体素的坐标对」作 hashmap key** 关联帧间接触（常规引擎要造唯一 contact ID）；
  - 手写多线程库（无锁调度）+ 接触图着色。
- 另：重构核心体素数据结构 + 重写修改算法 → 2x 提速、可组合性大增；体素对象可与主网格同等编辑。

## 对 gate 的启示
- **「坐标对作 hashmap key 做 warm starting」**与 gate「元件对/体素对作为状态表 key」是同一惯用法，凡涉及「帧间/tick 间持续关系」的缓存都可用。
- 他的数据结构重构结论（重写修改算法换来 2x + 可组合）呼应 gate 的 flood-fill 组件元数据增量维护——修改算法的可组合性是值得投资的方向。
- 「2D 玩具引擎先行验证数值算法」的方法论（#20 提出、本集实践）适用于 gate 未来任何数值模拟特性（流体/应力）。
- 若 gate 做破碎/断连：先分类 corner/edge/face/interior，检测裁剪与物理复用同一套标注。
