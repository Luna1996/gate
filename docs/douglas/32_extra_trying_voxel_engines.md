# 番外 - Trying OTHER PEOPLE'S voxel game engines（市场调研）

- 视频: https://youtu.be/uQgoJYtuCYs （17:20，2024）
- 类别: 其他 | ⭐⭐ 建造系统 UX 调研：Terafy / Teardown / Ray 的 path tracing 引擎

## 一句话
为自家建造系统做竞品调研，试玩三款体素游戏总结建造 UX 得失：网格吸附是刚需、undo 是刚需、光标投影模式（自由悬浮 vs 贴合表面）决定建造手感。

## 内容要点
- **Terafy（Frozen）**：观感极佳（大气/云/草，世界"活"）；地形雕刻 + 道具摆放两类工具，**道具不可体素编辑**（地形抬升不带动道具）；地形上色只有约 10 体素深（挖开露出底材）；冰柱透明渲染 + 光照浸染（雪被冰映蓝）完成度高；推测用 per-voxel normals 且 Sculpt 时更新方式是谜。15 分钟能搭出漂亮场景 → 拖放直觉性价值高。
- **Teardown**：战役 5 小时体验（两阶段抢劫 + 60 秒逃离）；物理极稳（堆叠物体不抖动），归因于**同时求解器**（vs 他自己的迭代求解器抖动）；建造模式偏自由雕刻：自由画/线/盒，左键悬浮光标、右键投影到表面；**无网格吸附 → 对齐/对称困难**；**无 undo → 强烈缺失感**；关卡本体是 MagicaVoxel 制作导入。
- **Ray 的 path tracing 引擎（未发布）**：全路径追踪 + 动态草/树（John Lin 点赞）；建造系统最接近理想：**可变粒度网格吸附**（滚轮切 1×/2×/4× 对齐）+ 独立尺寸的球/盒笔刷 + Ctrl 拖盒填充；缺点：框选角点不跟准星、拖选不直观。微体素粒度能做百叶窗/窗沿细节。
- **他的结论**（= 建造系统需求清单）：网格吸附必须有、粒度可切换、undo/redo 必须有、光标投影模式要可预期、删改工具与建同权重。

## 对 gate 的启示
- 直接喂 gate P4 编辑器设计：**可变粒度吸附网格**与 gate 的多分辨率（4cm/1cm/0.25cm）天然对齐——粒度切换机制正是 UNRESOLVED 决策点（P4.1 动工前裁决），本篇证据支持「滚轮切粒度」。
- undo/redo 必须进 P4 范围（Teardown 的缺失被反复吐槽）；多人下 undo 他也没解，gate 可先做单操作 undo 栈。
- 电路元件（gate 的"道具"层）与体素地形分离编辑，与 Terafy 的道具不可编辑缺点一致——gate 的 flood-fill 元件本来就独立于体素，天然规避。
- 光标投影两模式（悬浮/贴面）都保留、右键切换，是低成本高收益的手感项。
