# Devlog #14 - GORGEOUS, speedy terrain generation

- 视频: https://youtu.be/m4-toCACxKU （12:20，2023）
- 类别: 玩法 | GPU 程序化地形 + 区间算术跳空

## 一句话
地形生成管线变成数据（字节码→拼接成 shader→GPU 执行→CPU 组八叉树），用区间算术预判同质区域跳采样（地表 chunk 只算 20-30% 体素），3D 模型区域用距离场 O(1) 判同质。

## 内容要点
- **CPU→GPU 的理由**：多线程 CPU 版仍抢主线程算力；硬编码管线编译后不可改——目标是引擎级可定制。
- **管线即数据**：地形生成器 = 低层指令列表（向量加减乘/随机数）→ 字节码可序列化、可运行时修改 → 每条指令一个 WGSL 片段，**拼接成完整 compute shader** → GPU 生成 → 读回 CPU → 组装八叉树。未来做节点编辑器/语言前端编译到该字节码。
- **区间算术跳同质区**（本集核心）：管线是纯函数（体素位置→实数→>0 空气/≤0 泥土）；对输入区间预测输出区间（2x、e^x 等单调/可推广函数，含 and/or/if 逻辑）→ 输出区间整段同号 → **整块 16³ 直接赋同值，逐体素采样全部跳过**。实现：两份 shader——区间版 + 逐体素细采样版（视频里有个 bug 现场：fine shader 没跑，正好显示哪些 16³ 块被整块跳过）。效果：地表有树石草的 chunk 也只算 20-30%，天空/地下近乎 100% 跳过。
- **含 3D 模型的区域**：数学预测失效 → **距离场判同质**：预计算 16 倍降采样模型的 DF，若「DF(min corner) > bbox 边长」则整盒同质（取角点值），否则逐体素采。高低分辨率模型 + DF 都上 3D 纹理；八叉树打包时同质区不占 GPU 内存。

## 对 gate 的启示
- **「DF > 盒边长 ⇒ 同质」是 #12 CCL 技巧的一般化**：gate 的 flood-fill / 组件重算可以用同一条判定跳过大块同质区——在 tile 构建时顺带算一张粗 DF（或直接用现有 bitmask 粒度），flood 时 O(1) 吞掉整块同质体。
- 区间算术对 gate 的场景生成器（若做沙盒世界生成）是现成方案；对**电路模拟的静态区域预判**也有启发：无源区域在拓扑不变时可直接复用上次结果（「区间版/细算版」对应「粗判版/精算版」两级 shader/两级行为）。
- 「管线即数据、拼接生成 shader」的模式若 gate 未来给元件行为/材质规则做数据驱动（StateTable 扩展），是可复用的架构形态。
