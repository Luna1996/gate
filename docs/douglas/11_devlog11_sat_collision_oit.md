# Devlog #11 - Making voxels MOVE with the separating axis test

- 视频: https://youtu.be/PW1Xwc3zzNc （14:08，2023）
- 类别: 物理 | 附带 OIT 透明裁决

## 一句话
自研体素 SAT 碰撞检测（放弃 PhysX）：网格对齐的线性性质让逐体素投影只需 1-2 次矩阵乘，八叉树空节点整块免检；透明选加权 OIT 而非排序。

## 内容要点
- **自研 vs PhysX 的裁决**：通用库拿不到针对「体素八叉树 vs 盒/体素八叉树」的特化优化 → 自研。体素的天然优势：底层数据就是体积表示，不需要 box/capsule 近似。
- **SAT（分离轴定理）**：3D 凸盒需检查 15 条分离轴（含棱/角 case）；投影区间中央的间隙 = 需要移动的最小距离 → 可**预测碰撞**（continuous collision detection，防穿墙/tunneling）。
- **线性性质优化**（本集最有价值的技巧）：体素全部网格对齐——把一个体素平移+缩放到另一个体素，其在分离轴上的投影区间做同样的平移+缩放即可。于是只需对「原点处单位体素」算一次投影区间，之后每对体素碰撞检测**仅 1-2 次矩阵乘**（区间线性变换），大幅削减逐体素计算。
- **八叉树空区免检**：大空区是单个稀疏节点 → 与其他对象的该区域碰撞检测直接跳过。
- **透明裁决**：精确需要逐像素排序（太贵）；Minecraft 式三角形排序在复杂凹形场景下又贵又可能破功 → 选**加权 OIT**（按 alpha 平均颜色再与场景混合），一个额外 pass，观感与排序几乎不可区分，还为水体铺路。

## 对 gate 的启示
- 碰撞检测未在 gate 当前 MVP 路径上，但「单位体素预计算 + 线性变换复用」与 gate「预算 SVG 相对标尺」同属空间对齐红利，记档备用（若做可破坏场景/物理对象）。
- OIT（#16 加权函数版）两集互相印证：透明裁决 = OIT + 距离加权，未来水/玻璃直接采用，跳过三角形排序路线。
