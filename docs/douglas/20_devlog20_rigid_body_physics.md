# Devlog #20 - Coding rigid body physics for voxels

- 视频: https://youtu.be/byP6cA71Cgw （13:15，2024）
- 类别: 物理 | 物理引擎 v2 架构集

## 一句话
重写刚体物理：借鉴 Teardown 技术演讲用「角/棱体素」裁剪接触点，用「变换中心 + 查 8 邻域」替代精确 SAT，迭代式接触求解器保证动量守恒。

## 内容要点
- **v1 的失败**：一次只解一个对象（其他全当静止）→ 力不传递、堆叠失效；一个迷你体素能把大树钉死在地上；能量/动量不守恒。
- **碰撞检测 v2**（源自 Teardown 作者 Dennis Gustafsson 公开技术演讲）：
  - 多面体碰撞只会发生在**角（corner）或棱（edge）体素**上——定义：沿某轴两侧都有邻居的才不算 corner；仅一个轴两侧有邻居的才是 edge；
  - 对象生成时构建加速结构只记录 corner/edge 体素；检测时「corner vs 对方全体素 + edge vs edge」→ 测试更少、接触点锐减（地面上的盒子只产生 corner 接触）；
  - 体素对体素精确 SAT 太贵也没必要：把一方体素中心**变换到对方坐标系**，查最近的 8 个体素是否有实心即判碰撞——等效于把小体素当小球，副作用是物体更容易滚动/滑动（观感反而自然）。
- **碰撞求解 v2**：读 Ian Millington《Game Physics Engine Development》；**迭代式求解器** = 位置调整 + 速度调整两阶段，取接触列表逐个解，每次解完更新其余接触数据，循环直到全部解除穿透且动量传递完成——多接触同时求解无解析解，迭代是工业界标准答案。
- **方法论**：先写 2D 版再上 3D（他自己第一步就该这么干）。

## 对 gate 的启示
- 「删除地形 → 断连区域成为独立刚体」依赖**连通性检测**——gate 的 flood-fill 连通体素组件语义天然提供这个能力（电路导线断开、部件脱落同一套机制），未来加可破坏场景时架构上已就位。
- Teardown 的 corner/edge 裁剪思想可推广到 gate 的 DDA/拾取：只关心「结构特征体素」而非全部表面体素。
- 「8 邻域近似替代精确求交」是 gate 做体素拾取/编辑刷命中判断时可用的精度-速度旋钮。
