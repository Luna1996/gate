# Devlog #16 - How I tripled the render distance in my game engine

- 视频: https://youtu.be/74M-IxtSVMg （13:50，2024）
- 类别: 基础渲染 | 同时含天空盒与透明度（对应 gate v3.5a / 水体远期）

## 一句话
服务端「按 LOD 粒度直接生成 + 脏区记账」让渲染距离×3；顺带做了昼夜天空盒和 OIT 透明。

## 内容要点
- **动机**：Ethan Gore 的 4B³ 体素世界——真存下来是天文数字，秘密就是 LOD。
- **LOD 生成的新思路**：旧法服务端先载全质量 chunk、客户端下采样 → 服务器被迫模拟玩家背后 5 chunk 的世界，浪费。新法：**地形生成器原生支持多尺度**（1/2/4/8 世界单位每体素），客户端要哪级 LOD 就直接生成哪级，跳过全质量。客户端把世界组织成八叉树，屏幕上每个立方块（不论大小）渲染开销相同。
- **编辑与 LOD 的兼容**（最关键、最繁琐的部分）：
  - LOD 生成后缓存并**存盘**；
  - 用户编辑 → 标脏 → 沿 LOD 八叉树向上标记所有外层 octant「自上次生成后已被编辑」；
  - 请求高级 LOD 时：先读盘缓存，再对**脏子八分体**取更高一级 LOD 下采样并重组 → 编辑在拉远后依然可见（他最自豪的点）。
- **程序化天空盒**：完整昼夜循环 + 太阳/月亮/星星 + 可配置背景色 + **可调云量**（晴天/阴天场景随建）；计划把昼夜循环做成玩法机制。
- **OIT 透明**：收集同一像素所有片元做加权平均混合——加法+乘法与顺序无关，免除 back-to-front 排序；初次实现漏了**按"距相机近的权重高"的加权函数**导致观感怪异，补上后近似正确的遮挡关系。
- 背景：OpenGL → WebGPU 迁移中；自评 greedy meshing + voxel rasterization 已到顶。

## 对 gate 的启示
- **v3.5a 程序化天空**直接对标本集：昼夜循环 + 太阳盘 + 云层可调 + 背景色可配置，正好是「自然日光」主题资产的组成清单；他后续把昼夜做成玩法也可借鉴（电路解谜对光照环境的依赖）。
- 「LOD 粒度直接生成 + 脏区向上传播 + 按需重组」与 gate 的「长未用 refinement 合并回 + 编辑触发放大」是同一问题的服务端版，合并/下采样策略可互抄。
- OIT 加权平均是未来水/玻璃的现成方案（记得带距离加权函数）。
