- [ ] **R2-2（3.5e）** **方向位掩码 LUT 预过滤（对标 #18「提速一倍」核心项，1660 降档池候选）**：编译期生成查找表 `(入口位置 × 主方向组合) → 该射线可能命中的体素位掩码`——**与数据无关的纯几何先验**（#18 字幕确认），运行时 occupancy mask AND 方向 mask = 0 → 整块跳过（几条 GPU 指令）；与现有 u32 word 跳空 + 两级 DDA 叠加，纯收益项；**LUT 规模关键结论**：依赖 R2-3 ② 的 per-cell 64-bit L2 mask——LUT 只需覆盖 4³ 中块粒度，入口 16²×6 面 × 8 方向桶 = 12288 项 × 8B = **96KB 常量 buffer**（若按 fine 粒度 4096-bit mask 需 6MB，不划算）；粗步进 cell 前一条 AND 即可跳过整个 cell 的细步；**降档触发点**：3.7 性能验收若 1660 不达标则启用
- [ ] **R2-3（3.5f）** **DDA 访存压缩三件套（对标 #17/#18「内存读是头号敌人」，1660 降档池候选，按序递进）**：①**细步寻址链缓存**（小改纯收益，可先行）——同一 cell 内 ①TileIndex ②TileBitmaps ③CellDirs+hdr 完全不变，粗步已查 ①②，进 cell 后缓存 node_abs/hdr/基址，细步采样从全链 ≤8 load 降到 L1→L4 walk 4~5 load（省 ~40% 细步访存；`trace_world` 细步与 `obj_fine_scan_cell` 同病同治，CPU 参考实现同步改 + 等价单测锁）；②**per-cell 64-bit L2 occupancy mask**——gate L2 恰 64 slot（4³ 中块）与 Douglas u64 brick mask 一一对应：构建期为每 cell 追加 8B（L2 slot tag≠EMPTY 位图，+256KB/tile，10 tile 大陆 +2.5MB 可接受），细步进 cell 2 load 取进寄存器，fine DDA 每步位测试零内存读、命中空 L2 slot 直接跳 4 fine（Douglas「mask 进寄存器后最多 10 步零内存读」的 gate 化映射）；③**tile 级第三级 DDA**——当前粗步 cell 粒度穿过空 tile 要 32×cell 步 × 2 load，加 tile 级 DDA（TileIndex 1 load 判空 tile 一步跨 512 fine）；固定比例地址链（512/16）使三级全 DDA 可行——#18 Douglas 公开悬赏「跨层级 DDA」未解决，gate 结构天然可解，反向确认 gate 两级 A&W 是该开放问题的一种答案
- [ ] **R2-4（3.5g）** **Beam 两级渲染 + 阴影降档（对标 #18，1660 降档池首选）**：①**Beam**——低分辨率 pass 完整跑 trace+shade 额外输出 R32F 命中距离 t，全分辨率 pass 以周围 4（斜向布局 6）条低分辨率射线的 **min(t) 为射线起点**（平均空域行程大幅缩短），低分辨率覆盖深度之外从 0 正常步进；**保守性证明**（#18）：低分辨率 pass 限制步进深度，保证「任何大到足以覆盖某全分辨率像素的体素」必被某条低分辨率射线命中 → 输出与非 beam 版**逐像素一致**；**OBJ 物体必须在低分辨率 pass 内参与**（一致性前提）；当前 RenderScale 全分辨率 1:1 无降采样，beam 优于纯半分辨率（着色保持全分辨率且可证明无误差）；②**阴影降档**（beam 思想变体）——阴影是低频信号：半分辨率阴影可见性 + 全分辨率主射线，或软阴影锥采样多样本共享低分辨率可见性（与 3.5d 逐面管线合流：逐面 1 条阴影射线已是天然降档形态）；**降档触发点**：3.7 验收 1660 不达标启用
